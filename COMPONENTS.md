# Fakoli CMS Components

Brief description of each component in `cms/components/`.

| Component | Description |
|---|---|
| `activity_tracker` | Monitors user interactions and collects user feedback. |
| `admin` | Core support for the administration section. |
| `api` | Provides remote API hooks for Fakoli components. |
| `article` | Article creation and management. |
| `attachment` | File attachment handling for other components. |
| `auto_login` | Automatic login via pre-shared tokens, primarily for authenticating scheduled tasks. |
| `blog` | Basic blog functionality. |
| `bookmark` | Allows users to bookmark internal pages. |
| `calendar` | Calendar display and event handling. |
| `captcha` | Integration with captcha services to reduce spam. |
| `classification` | Basic classification/categorisation functionality (currently disabled). |
| `color_picker` | Color picker control and field renderer. |
| `comment` | Commenting functionality attachable to other components. |
| `component` | Component registry and management. |
| `connectable` | Free-form relationship engine with navigation between connected items. |
| `context_help` | Inline contextual help within Fakoli admin forms. |
| `dashboard` | Simple dashboard layout for admin home screens. |
| `data_sync` | Generic data import framework. |
| `date_picker` | Advanced MooTools-based date/time picker, replacing the standard Fakoli date picker. |
| `debug` | Trace statements and test harnesses for development. |
| `developer_tools` | Reports and tools for understanding a Fakoli application's configuration and structure. |
| `document` | Document upload and management, including thumbnail generation. |
| `email` | Email composition and delivery management. |
| `error_log` | Error logging and improved error display. |
| `field_renderers` | Custom field renderers shared across CMS components. |
| `fileshare` | Collaborative document library file sharing. |
| `forum` | Discussion forum functionality. |
| `glossary` | Managed list of terms and definitions. |
| `html_editor` | Configuration and extensions for the TinyMCE HTML editor. |
| `image` | Image upload and management. |
| `image_picker` | Image picker for use within the rich text editor. |
| `link_library` | A simple curated collection of links. |
| `link_picker` | Link picker for use within the rich text editor. |
| `login` | Standard user login and session management. |
| `menu` | Site menu creation and management. |
| `mobile_settings` | Detects mobile browsers and applies mobile content-selection rules. |
| `module` | Module (page widget) management. |
| `online_help` | Online help framework for Fakoli applications. |
| `open_data` | Open Data compliance and publishing support. |
| `optimize` | CSS and JavaScript optimisation/minification for production. |
| `page` | Core page management. |
| `panel_layout` | User-configurable panel layout for pages. |
| `pdf` | PDF generation via wkhtmltopdf. |
| `phonegap` | Support for PhoneGap mobile applications. |
| `process` | Spawns background processes and reports on their progress. |
| `questionnaire` | Custom questionnaires, surveys, and quizzes. |
| `rating` | Page and content rating. |
| `recaptcha_v2` | reCAPTCHA v2 captcha provider. |
| `redirect` | Redirects resources that have changed identifier or moved section. |
| `report_manager` | General-purpose configurable reporting screens. |
| `role` | Role-based access control management. |
| `rss_feed` | Consumes and displays external RSS feeds. |
| `scheduled_task` | Scheduling and execution of periodic background tasks. |
| `scroll` | Long scrolling pages composed of multiple content blocks. |
| `search` | Unified site search. |
| `section` | Site section management. |
| `session_extender` | Keeps a user's session alive by periodically pinging the server. |
| `session_persistance` | Database-backed PHP session persistence for high-availability deployments. |
| `settings` | Application-wide settings management. |
| `sharing` | Shares work products with external parties without requiring a login. |
| `site` | Core site definition and configuration. |
| `site_map` | Generates and displays the site page hierarchy. |
| `slideshow` | Zoomable image slideshow. |
| `social_media` | Social media integration. |
| `survey` | Custom questionnaires with token-based or anonymous responses. |
| `svg` | Embeds SVG files directly into CMS pages. |
| `svg_charts` | Charts and graphs rendered via Raphael.js. |
| `taxonomy` | Taxonomy and tagging management. |
| `template` | Template and CSS administration. |
| `terms_and_conditions` | Terms and conditions display and approval tracking. |
| `text_lookup` | Multilanguage text data repository and lookup. |
| `tool_hints` | Dismissable popup hints providing introductory guidance. |
| `user` | User account management. |
| `versioned_content` | Content versioning, version management, and approval workflows. |
| `video` | Video upload, galleries, and video blogs. |
